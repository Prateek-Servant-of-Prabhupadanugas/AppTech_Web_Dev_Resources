# 🖥️ Engineering Core // Dynamic Project Hub

Welcome to the **Engineering Core Master Hub**—an interactive, production-ready developer portfolio dashboard. This application functions as a centralized command center designed to host, showcase, and deploy high-fidelity frontend modules, technical capstones, and responsive curriculum milestones.

Built completely with native, semantic HTML5 and vanilla CSS3, this interface integrates smooth multi-layered 3D parallax hover mechanics driven by low-latency JavaScript event loops.

---

## 🚀 Core Architectural Features

* **3D Perspective Matrix:** Implements native CSS spatial configurations via `perspective` and `transform-style: preserve-3d` to project container elements forward along the Z-axis.
* **Fluid Grid Autoflow Engine:** Orchestrates grid layouts utilizing `repeat(auto-fit, minmax(300px, 1fr))` to execute completely fluid, breakpoint-free responsive column sorting across modern mobile and desktop screens.
* **Anti-Clashing Content Sandboxing:** Employs explicit internal layout flex vectors (`flex-direction: column` and `justify-content: space-between`) to ensure title assets, technical badges, and live action links never shift or overlap, even during maximum portrait orientation compression.
* **GPU-Accelerated Trailing Loops:** Dynamically catches real-time mouse movement offsets relative to container midpoints, bypassing traditional animation lag filters by interacting directly with device hardware graphics engines.
* **Immersive Cyberpunk Aesthetics:** Features real-time linear keyframe scanner animations, backdrop filter blurs, and localized neon luminescence accents to provide a premium operating dashboard feel.
